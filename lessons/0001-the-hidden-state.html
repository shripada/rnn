Lesson 1 · Recurrent Neural Networks · ~20 min

The Hidden State

One loop, one vector, and the whole idea of an RNN.

By the end you can draw an unrolled RNN, write its update equation from memory, and explain in one sentence why it can read a sequence of any length. That is the first five minutes of almost every RNN interview question.

The problem: networks with no memory

A feed-forward network, the kind you already know, takes a fixed-size input and returns an output. Every input is processed in isolation: nothing carries over from one call to the next.

Language, audio, stock prices and sensor readings are sequences. Their meaning depends on order and on what came before. Colah's example: in I grew up in France… I speak fluent      , the word you need is set by context several words back.2 A feed-forward net has two problems here:

  1. It wants a fixed input size, but sentences have different lengths.
  2. It has no memory, so it can't use what it saw earlier.
“The core reason that recurrent nets are more exciting is that they allow us to operate over sequences of vectors.”Andrej Karpathy, The Unreasonable Effectiveness of RNNs

The idea: feed the network its own output

An RNN reads the sequence one element at a time. At each step it takes two things in: the current input xt and its own hidden state from the previous step, ht−1. It combines them into a new hidden state ht.

The hidden state is a vector that works as a running summary of everything seen so far. That vector is the network's memory.

ht = tanh( Whh·ht−1 + Wxh·xt + bh )
yt = Why·ht

Two terms inside the tanh: one from the previous hidden state, one from the current input.1 The hidden state starts at h0 = 0. Read the subscripts as “to, from”: Wxh maps x into h.

Look at the equation. It's an ordinary dense layer with one extra input, and that extra input is the layer's own previous output. Everything else about RNNs follows from this.

Unrolling: the loop drawn out over time

“A recurrent neural network can be thought of as multiple copies of the same network, each passing a message to a successor.”Christopher Olah, Understanding LSTM Networks

Unrolling doesn't add any parameters. It's only a way of drawing the computation so you can see the time steps, and you'll need this picture when we get to training (backpropagation through time).

Parameter sharing: why any length works

The same three weight matrices are reused at every time step. A 5-word sentence and a 500-word essay run through the exact same weights; the essay just takes more loop iterations. As Dive into Deep Learning puts it, “the parametrization cost of an RNN does not grow as the number of time steps increases.”3

This one design choice answers both problems from the top of the page:

  • Any length: you keep looping until the sequence ends.
  • Memory: ht carries information forward from step to step.

It also generalises across positions: a pattern learned at step 3 is recognised at step 30, because the same weights are applied at both.4

“An RNN applies the same cell at every time step. The cell combines the current input with a hidden state carried over from the previous step, so the hidden state acts as a memory of the sequence so far. Because the weights are shared across time, the model handles variable-length sequences with a fixed number of parameters.”

Shapes (interviewers love these)

Suppose each input xt has d features, the hidden state has n units, and the output has k values. Using column vectors as above:

MatrixMapsShape
Wxhinput → hiddenn × d
Whhhidden → hiddenn × n
Whyhidden → outputk × n

Dive into Deep Learning (D2L) writes the same equation with row vectors (XtWxh), so its matrices are the transposes of these.3 If asked, state which convention you're using. Whh is square in both.

Play: a one-number RNN

Here's the smallest possible RNN: the input, hidden state and every weight is a single number. The input sequence is a single “spike” at step 1 followed by zeros, so whatever shows up in h2…h6 is purely memory of that spike. Move the sliders and complete the three challenges.

○Amnesia. Make the network forget instantly: h2…h6 all zero, while h1 still reacts to the spike.
○Long memory. With b = 0 and the spike only at step 1, keep h6 ≥ 0.5.
○Flip-flop. With only the step-1 spike, make h change sign at every step.

Notice what you just found. With wh = 0 the recurrent term disappears and you have a plain feed-forward net applied at each step. With |wh| below 1 the memory fades a little more at every step, because the signal keeps getting multiplied by a small number. Keep that in mind: in Lesson 3 it becomes the vanishing gradient problem, which is why LSTMs exist.2

Check yourself

1. What does an RNN pass from one time step to the next?
The hidden state ht is the only thing that flows forward through time. The weights are fixed and shared, and the input arrives one element per step.
2. The same RNN reads a 10-step sequence, then a 1000-step one. How many distinct Whh matrices does it use?
That's parameter sharing. Unrolling only draws copies of the cell; the parameter count doesn't grow with sequence length.
3. Set Whh = 0 in a trained RNN. What have you effectively built?
With no recurrent term, ht = tanh(Wxhxt + b). Each step only sees its own input, which is exactly the Amnesia challenge.
4. Inputs have 3 features and the hidden state has 4 units. Shape of Wxh (column-vector convention)?
Wxh maps a 3-vector to a 4-vector, so it's (output × input) = 4 × 3. Whh would be 4 × 4. In Dive into Deep Learning's row-vector form it's written 3 × 4.
5. Why might a vanilla RNN struggle to use a word from 50 steps earlier?
You saw this in the simulator: with |wh| < 1 the spike fades geometrically. Colah: “as that gap grows, RNNs become unable to learn to connect the information.”2 More on this in Lesson 3.

Say it out loud

Answer each one aloud or on paper before you reveal it, the way you would in an interview. Struggling to recall is the point: it's what makes this stick.

Why can't a plain feed-forward network handle sentences well?
It needs a fixed input size and it has no memory between inputs. Sentences vary in length, and their meaning depends on earlier words.
Write the hidden-state update equation and name each part.
h_t = tanh(W_hh·h_{t−1} + W_xh·x_t + b_h): the previous hidden state, the current input, a bias, and a squashing nonlinearity. Output: y_t = W_hy·h_t.
Draw a 3-step unrolled RNN. What's shared between the boxes?
Three cells left to right, each with xt below, yt above, and an h arrow into the next cell. All three cells use the same Wxh, Whh, Why and b. Only h changes.
If you shuffle the order of the inputs, does the final hidden state change? Why?
Yes, in general. Each step's h depends on the previous h, so the computation is order-sensitive. Try it in the simulator with the input boxes. That order sensitivity is what makes RNNs suited to sequences.
