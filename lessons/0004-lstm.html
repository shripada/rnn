LSTM: Gated Memory

A second, protected memory that is updated by adding, not by squashing.

By the end you can draw an LSTM cell, write its six equations, say what each gate does in one sentence, and explain why the cell state lets the gradient survive many steps when a vanilla RNN's doesn't. That last part is the interview payoff: “How does an LSTM fix vanishing gradients?”

Warm-up: Lesson 3

Answer from memory, then reveal.

Why does the gradient vanish in a vanilla RNN? One sentence.
Going back k steps multiplies k per-step factors f = wh × tanh′, and when f < 1 the product fk shrinks exponentially.
Why can't gradient clipping fix vanishing?
Clipping only scales a gradient down. A vanished gradient has nothing left to scale up.
Lesson 3 said vanishing needs “an architectural fix”. What property would that fix need?
A path through time where the per-step factor can stay close to 1, so the signal isn't shrunk at every step. Keep this in mind: the LSTM's cell state is that path.

The idea: a second memory that is changed by adding

In a vanilla RNN, the whole memory goes through tanh(Whh·h + …) at every step. It gets multiplied by the same matrix and squashed every time, whether or not anything new happened. That repeated multiply-and-squash is exactly what killed the gradient in Lesson 3.

The Long Short-Term Memory (LSTM), from Hochreiter & Schmidhuber (1997),1 adds a second state vector, the cell state ct, which is not pushed through a weight matrix at each step. Each step can only do two simple things to it:

  1. erase some of it (multiply each entry by a number between 0 and 1), and
  2. write something new into it (add a vector).

Olah's image: The cell state is kind of like a conveyor belt.2 It runs straight through every step, and things are taken off it or put on it along the way. The ordinary hidden state ht still exists. It's the cell's output, a filtered view of what's on the belt.

Gates: learned valves

Who decides how much to erase, write and show? Small neural networks called gates. Each gate looks at the current input and the previous hidden state and outputs a vector of numbers between 0 and 1, using the sigmoid σ (an S-curve like tanh, but from 0 to 1 instead of −1 to 1). That vector is multiplied entry by entry (written ⊙) with whatever the gate controls.

Olah: Gates are a way to optionally let information through. A value of zero means “let nothing through,” while a value of one means “let everything through!”2

The key word is learned. The gates have their own weights, trained by BPTT like everything else, so the network learns when to remember and when to forget, based on what it's reading.

The LSTM cell

All four boxes read the same thing, [ht−1, xt] (the two vectors stacked), each with its own weights:

ft = σ( Wf·[ht−1, xt] + bf )    forget gate
it = σ( Wi·[ht−1, xt] + bi )    input gate
c̃t = tanh( Wc·[ht−1, xt] + bc )  candidate
ot = σ( Wo·[ht−1, xt] + bo )    output gate
ct = ft ⊙ ct−1 + it ⊙ c̃t
ht = ot ⊙ tanh(ct)

The first four lines are each “Lesson 1's equation with a different activation”. Only the last two are new, and they contain no weight matrices at all. Dive into Deep Learning (D2L) §10.1 writes the same thing in row-vector form with separate Wx· and Wh· matrices.3

PartRangeJob, in one sentence
Forget gate ft0…1How much of each entry of the old cell state to keep (1 = keep all, 0 = wipe).
Input gate it0…1How much of the new candidate to write onto the belt.
Candidate c̃t−1…1What could be written: a vanilla-RNN-style proposal built from the input.
Output gate ot0…1How much of the memory to reveal as ht, which is what the rest of the network (and the next step's gates) see.

Two states, two jobs. ct is the long-term store: it can hold a value unchanged for as long as the forget gate stays at 1. ht is the working output: the part of the memory that matters right now. D2L notes that with the output gate near 0, a memory cell can accrue information across many time steps without impacting the rest of the network.3

Play: you are the gates

A one-number LSTM over 8 steps. In a real LSTM the gate values are computed from the input; here you set them, playing the part of trained gate weights. Click a gate to cycle 0 → 0.5 → 1. To keep the arithmetic visible, the candidate is just c̃ = tanh(x). Bars fill with the size of each value: orange for positive, blue for negative.

○Store and hold. Write x1 into the cell and keep c between 0.9 and 1 at every step. (Watch out for the distraction at step 4.)
○Forget on cue. Hold c ≥ 0.9 through step 5, then make it exactly 0 at steps 6–8.
○Silent memory. Keep h at 0 for steps 1–7 but make h8 ≥ 0.7. The memory must be there all along without showing.
○Add it up. Get c8 above 1.5. A vanilla RNN's tanh output can never leave −1…1. Can the cell state?

What you just did, in words:

  • Holding needs f = 1 and i = 0. D2L: If the forget gate is always 1 and the input gate is always 0, the cell state will remain constant forever, passing unchanged to each subsequent time step.3 A vanilla RNN has no setting that does this; you saw its memory fade in Lesson 1.
  • Forgetting is a deliberate act (f = 0), not something that happens by accident. The forget gate wasn't in the 1997 LSTM; Gers, Schmidhuber & Cummins added it in 2000 so the cell could reset itself.4
  • Silent memory is what the output gate is for: separate “what I know” (c) from “what I say now” (h).
  • Adding up works because c is updated with +. It is a running sum, so it can count or accumulate evidence.

Why this fixes vanishing gradients

Use Lesson 3's tool: how much does a nudge to ct−1 move ct? Look at ct = ft ⊙ ct−1 + it ⊙ c̃t. Along the belt, the answer is simply:

∂ct / ∂ct−1 = ft   (along the belt, entry by entry)

So going back k steps along the belt multiplies k forget-gate values. Compare the per-step factor in each model:

Vanilla RNNLSTM cell state
Per-step factorWhh × tanh′ft
Weight matrix in the path?Yes, the same one every stepNo
Squashing in the path?Yes, tanh′ ≤ 1 every stepNo
Who sets it?Fixed by Whh; can't be both 1 for “remember” and different for “forget”The network, per step and per entry, based on the input
Can it sit at ≈ 1?Only at a knife edge (Lesson 3)Yes: f = 1 is just “keep”, a normal state for a gate

Hochreiter & Schmidhuber called this the constant error carousel: a self-loop with factor 1, so error can circulate back through time without shrinking.1 D2L describes the same self-connection as ensuring that the gradient can pass across many time steps without vanishing or exploding.3

○The long haul. With T = 100, keep the LSTM's signal at step 1 above 0.1 while the RNN's is below 10−6.
○Gate shut. With T ≥ 20, make the LSTM's signal vanish too (below 0.001). This is what forgetting looks like from the gradient's side.
○Same factor, same fate. With T ≥ 20, set the forget gate equal to the RNN's factor wh × tanh′ (within 0.005). What happens to the two curves?

The last challenge is the subtle point. The arithmetic is identical: both are “factor to the power k”. The difference is which factors are easy to reach. For the RNN, 0.99 needs wh and tanh′ both near 1 at every step, a knife edge that also fixes how fast everything fades. For the LSTM, 0.99 is just “forget gate open”, which a gate can output whenever the input calls for it, and close again when it doesn't.

Three honest caveats, all interview-worthy:

  • It isn't magic, it's learned. The belt only carries gradient while the forget gate is near 1. That's why a common practical trick is to initialise the forget-gate bias to a positive value (about 1), so the cell starts out remembering. Jozefowicz, Zaremba & Sutskever found this simple change helped LSTMs a lot.5
  • Only the belt is protected. Gradient also flows through h and through the gates, and those paths still have weight matrices and squashing. LSTMs alleviate vanishing; they don't make sequences of any length easy.
  • Exploding is less of a problem, but not gone. f ≤ 1, so the belt can't blow up, but the other paths can, so people still use gradient clipping with LSTMs. The demo does.

Shapes and cost

Each of the four boxes is a vanilla-RNN-sized layer: a matrix of shape n × (n + d) plus a bias of size n. So:

LSTM parameters = 4 × ( n·(n + d) + n )  =  about 4× a vanilla RNN with the same hidden size n

Both ct and ht have size n. Everything from Lessons 1–2 still holds: shared weights across time, any sequence length, same task shapes. You can drop an LSTM in wherever the diagrams in Lesson 2 had an RNN cell, which is what Sutskever et al.'s seq2seq model did.

It cost 3.5× the weights (347,457 vs 99,393) and about 3× the training time (80 s vs 24 s).

“An LSTM adds a cell state alongside the hidden state, controlled by three sigmoid gates. The forget gate scales the old cell state, the input gate scales a tanh candidate that gets added, and the output gate decides how much of tanh of the cell state becomes the hidden state. Because the cell state is updated additively, the gradient from ct to ct−1 is just the forget gate, with no weight matrix or tanh in between. When the forget gate is near 1, the gradient passes back through many steps without vanishing. It has about four times the parameters of a vanilla RNN.”

Check yourself

1. Which LSTM equation contains no weight matrix?
ct = ft ⊙ ct−1 + it ⊙ c̃t only multiplies entry by entry and adds. That's why the gradient along it is just ft. (ht = ot ⊙ tanh(ct) has no matrix either, but it isn't an option here.)
2. Why do the gates use sigmoid rather than tanh?
A gate is a valve: 0 = let nothing through, 1 = let everything through. Sigmoid's 0…1 range is exactly that. The candidate uses tanh because it's content, which can be negative.
3. You want the cell to hold a value unchanged for 50 steps. Which gate settings?
Keep everything (f = 1), write nothing (i = 0). That's the Store and hold challenge. The output gate doesn't affect what's stored, only what's shown.
4. Along the cell state, what is the per-step gradient factor ∂ct/∂ct−1?
ct = ft ⊙ ct−1 + …, so nudging ct−1 moves ct by ft. It's exactly 1 only when the gate is fully open, which the network learns to do when it needs to remember.
5. Hidden size n = 100, input size d = 50. Roughly how many weights in one LSTM layer?
4 × (n·(n + d) + n) = 4 × (100 × 150 + 100) = 60,400. A vanilla RNN of the same size is about 15,100, so the LSTM has 4× as many.
6. Why might a model keep something in ct but set the output gate near 0?
The output gate hides memory without erasing it. Example: remember an opening quote mark so you can close it later, without letting it affect every prediction in between. Erasing is the forget gate's job.

Say it out loud

Draw an LSTM cell and name the three gates, with one sentence each.
Belt along the top: ct−1 → × → + → ct. Forget gate (σ) feeds the ×: how much old memory to keep. Input gate (σ) times candidate (tanh) feeds the +: what new memory to write. Output gate (σ) times tanh(ct) gives ht: how much memory to show.
How does an LSTM fix vanishing gradients? 30 seconds.
The cell state is updated additively, so the gradient from ct back to ct−1 is just the forget gate: no weight matrix and no tanh at every step. When the forget gate is near 1 the gradient passes back almost unchanged over many steps. In a vanilla RNN the factor is Whh times tanh′, which is usually below 1, so it shrinks exponentially.
What's the difference between ct and ht?
ct is the long-term memory, changed only by gated erase and add. ht = ot ⊙ tanh(ct) is the output: a filtered view of the memory, used for predictions and fed to the next step's gates. Both have size n.
