RNN Core Cheat Sheet

The vanilla RNN and its gated successors. Grows as the course does.

The equation

ht = tanh( Whh·ht−1 + Wxh·xt + bh )
yt = Why·ht
h0 = 0

Subscripts read “to, from” (Wxh: x → h). Column-vector convention as in Karpathy; Dive into Deep Learning (D2L) §9.4 uses row vectors (XtWxh), which transposes the matrices.

Parameter count: n·d + n·n + n + k·n (+ k). It is independent of sequence length T.

Key ideas

IdeaOne-linerSource
RecurrenceThe cell's previous output (ht−1) is fed back in as an extra input.Karpathy
Hidden stateA fixed-size vector summarising the sequence so far; the only thing passed forward in time.D2L §9.4
UnrollingDrawing the loop as a chain of identical cells, one per time step. Adds no parameters.Olah

Order sensitivityShuffling inputs changes hT, because each step depends on the previous one.Lesson 1
Fading memoryRepeated multiplication by |w| < 1 shrinks old information step after step. This is the root of vanishing gradients.Olah

Task shapes

Same cell every time; the task decides which steps get an input and which outputs are used. Shapes from Karpathy; seq2seq from Dive into Deep Learning §10.7.

ShapeInputs → outputsOutput read fromExample
One-to-one1 → 1(no recurrence)Image classification
One-to-many1 → TEvery step; each output fed back as next inputImage captioning, generation
Many-to-oneT → 1Final hidden state hT onlySentiment, spam, forecasting one value
Many-to-many (synced)T → T, alignedEvery stepWord tagging, per-frame video labels, char-RNN training
Encoder–decoder (seq2seq)T → T′, unalignedDecoder steps, until <eos>Translation, summarisation

Aligned? If output t corresponds to input t, use synced. If not (lengths or order differ), use encoder–decoder: the encoder's final hidden state is the fixed-size context vector c, which is the bottleneck that attention later removes (Bahdanau et al. 2014).

Training: BPTT & gradients

BPTT = unroll, then ordinary backprop over the chain (Dive into Deep Learning §9.7). Shared weights → the gradient of Whh is a sum of contributions from every step.

Gated cells: LSTM & GRU

σ = sigmoid (0…1), ⊙ = entry-by-entry product, [h, x] = the two vectors stacked. Every W has shape n × (n + d).

Hold a value: LSTM f = 1, i = 0; GRU z = 1. Why gates fix vanishing: the memory is updated by adding, so the gradient along it is just a gate value, which the network can keep near 1 (no weight matrix, no tanh in the path). Tip: initialise the LSTM forget-gate bias to about 1 (Jozefowicz et al. 2015). Which? Similar accuracy (Chung et al. 2014, Greff et al. 2015); GRU is lighter, LSTM can hide memory. Pick by validation score.

Interview one-liner

“An RNN applies the same cell at every time step. The cell combines the current input with a hidden state carried over from the previous step, so the hidden state acts as a memory of the sequence so far. Because the weights are shared across time, the model handles variable-length sequences with a fixed number of parameters.”
